# Contributing to Culture Hub

Thanks for your interest! Quick guide:

- Fork the repo and create a branch per feature: `git checkout -b feat/my-feature`
- Add tests where possible.
- Keep UI changes accessible and responsive.
- Use `VITE_TMDB_API_KEY` in `.env` for local TMDB access.

Code style
- JS: use ESLint (prettier optional)

Issues & PRs
- Fill the issue templates provided in `.github/ISSUE_TEMPLATE/`.
- Provide screenshots and reproduction steps for bugs.
